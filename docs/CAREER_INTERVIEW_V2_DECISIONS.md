## Part 1. 변경사항 마스터 표 (확정 13개)

| # | 변경 영역 | 결정 | 이전 → 이후 |
|---|---|---|---|
| 1 | 턴 제어 | 옵션 A. 시간 정보만 컨텍스트로 주입, AI 자유 판단, 예산 강제 없음 | 결정적 6질문 + follow-up 1~2회 → 자유 흐름 |
| 2 | 시간 정보 수집 | 인사 직후 코치 발화로 자연어 질문 ("오늘 시간이 어느 정도 되세요?") | 별도 UI 없음 / 자연어로 수집 |
| 3 | 시간별 깊이 조절 | "짧게 / 보통 / 깊이" 3단계, "한 가지에 집중" 공통 메시지 + 깊이 단어만 차이 | AI가 사용자 응답을 해석해 깊이 자동 조정 |
| 4 | 초반 안내 | 코치 발화 내 안내만 ("중간에 멈추고 싶으면 언제든 말씀해주세요") | UI 상시 카드 없음 |
| 5 | 오프닝 질문 | 단일 고정: "지금 갖고 있는 가장 큰 커리어 고민이 뭔가요?" | 메인 6질문 → 단일 오프닝 |
| 6 | 인터뷰 흐름 | ICF MCC 8개 역량 기반 자유 탐색. 한 가지 주제에 집중, 미래 비전 등 강제 탐색 없음 | "목표를 명료하게 하고 에너지를 집중" |
| 7 | 코칭 합의 페이즈 | 신규 추가 (오프닝 → 한 번 펴기 → 합의) | 명시적 합의 페이즈 추가 |
| 8 | 합의 재조정 | AI가 표면/진짜 이슈 차이 감지 시 합의 재조정 *제안* (결정권은 사용자) | "Establishes & Maintains Agreements" 역량 |
| 9 | "잘 모르겠어요" 처리 | 4기법 + 3회 반복 시 탐색 중 합의 형성 fallback | 선택지 안 주고 구조화 돕기 |
| 10 | 정서 위기 가드레일 | 3단계 신호 (🔴/🟠/🟡) + 단계별 redirect 멘트 + 외부 자원 안내 | 1문장 → 구체화 |
| 11 | 추출 스키마 | 신규 4키 + 기존 7키 모두 optional + `session_duration_choice` | JSONB 구조 변경 |
| 12 | 종료 감지 | 자연 종료(코치 키워드) + 사용자 주도 종료(사용자 키워드) 2-path, 모두 클라이언트 측 텍스트 매칭 | 단일 path → 2-path |
| 13 | 시간 정보 저장 | `session_duration_choice` 컬럼 추가 (enum: short/medium/long) | DB 컬럼 신규 |

## Part 2. 새 인터뷰 흐름 구조 (4 Phases)

```
[Phase 1: Opening] (1~3턴)
  코치 1턴: 인사 + "중간에 멈춰도 된다" 안내 + 시간 질문
  사용자 2턴: 시간 자연어 응답
  코치 3턴: 시간 반영 + 오프닝 질문
           "지금 갖고 있는 가장 큰 커리어 고민이 뭔가요?"

[Phase 2: Echo & Agreement] (2~4턴)
  사용자: 고민 표현
  코치: echo-back 한 번 (B 패턴, 사용자 답 펴기)
  사용자: 더 설명
  코치: 합의 질문 (A 패턴)
       "오늘 이 대화가 끝났을 때, '아 이거 하나는 좀 풀렸다' 싶은 게 뭐라면 좋을까요?"
  사용자: 합의 응답 (또는 "잘 모르겠어요" → E 패턴 활용)
  코치: 합의 미러링 ("그럼 오늘은 ○○이 더 또렷해지는 걸 목표로…")

[Phase 3: Exploration] (시간 대부분, 자유 흐름)
  합의된 목표에 비춰 AI 자유 탐색
  - B, C, D 패턴 활용
  - 강점 페어 컨텍스트 20문장은 *암묵* 단서로만 활용 (직접 호명 금지)
  - 표면→진짜 이슈 시그널 감지 시 F 패턴으로 합의 재조정 *제안*
  - 정서 위기 신호 감지 시 단계별 redirect

[Phase 4: Closing] (1~2턴)
  코치: G 패턴 ("오늘 어떤 게 손에 잡히셨어요?")
  사용자: takeaway 표현
  코치: H 패턴 (자연 종료 발화) → 클라이언트가 키워드 감지하여 종료

[Extraction] (코드, AI 호출 1회)
  대화 전체 → 신규 4키 + 기존 7키(optional) + mentioned_competencies + ai_summary
```

## Part 3. 시간 정보 처리 규칙

| 사용자 응답 패턴 | 내부 깊이 레벨 | DB 저장값 | 코치 반영 멘트 |
|---|---|---|---|
| "15분", "20분", "짧게", "급해요" | 짧게 | `short` | "○분이면 한 가지 핵심을 또렷하게 만들어볼 수 있어요" |
| "30분", "40분", "보통" | 보통 | `medium` | "○분 동안 한 가지 주제를 충분히 들여다볼 수 있겠네요" |
| "1시간", "충분히", "시간 많아요" | 깊이 | `long` | "한 가지 주제를 깊이 있게 다뤄볼 수 있는 시간이에요" |
| 시간 안 밝힘, 모호 | 보통 (기본값) | `medium` | 시간 언급 없이 "그럼 시작해볼게요" |

## Part 4. 코칭 질문 패턴 (최종 8개 카테고리)

**핵심 원칙**: AI는 이 문장을 그대로 복붙하지 않음. **결의 틀**로 활용해서 매번 다른 표현으로 변주. 시스템 프롬프트 배치는 (a) 방식 — `system_prompt.md`에 카테고리 + 1~2개 짧은 예시 / `03.career_interview_v2.md`에 단계별 활용 + 인터뷰 맥락 특화 표현.

### A. 합의를 끌어낼 때
1. "오늘 이 대화가 끝났을 때, '아 이거 하나는 좀 풀렸다' 싶은 게 뭐라면 좋을까요?"
2. "오늘 다 하고 나면 어떤 상태가 되어 있으면 좋겠어요?"

### B. 사용자 답을 펴는 (Echo-back & Deepening)
1. "○○라고 하셨는데, 그게 어떤 의미일까요?"
2. "지금 ○○라는 말씀에서 가장 무겁게 느껴지는 부분이 어디예요?"
3. "그 순간을 조금 더 들려주실 수 있을까요?"

### C. 표면 → 진짜 이슈로 내려가는
1. "그 고민의 가장 아래에 뭐가 있을까요?"
2. "지금 이야기하시는 중에, 무엇이 가장 자주 돌아오는 것 같으세요?"
3. "그 일이 ○○님에게 왜 그렇게 중요한 거예요?"

### D. 새 관점을 일깨우는 (Evoking Awareness)
1. "지금 ○○이라고 말씀하셨는데, 처음 ××라고 하신 것과 어떻게 연결되는 것 같아요?"
2. "만약 지금 그 상황을 옆에서 보고 있는 친구가 ○○님께 한 마디 한다면 뭐라고 할 것 같아요?"
3. "1년 뒤의 ○○님이 지금 ○○님을 본다면 어떤 말을 해주고 싶을까요?"

### E. "잘 모르겠어요"를 받을 때
1. "그럼 이번 주에 일하면서 가장 무겁게 느껴진 순간 하나만 떠올려보실래요?" *(시간/감각 차원 분해)*
2. "잘 모르겠다는 그 감각 자체는 어떤 느낌이에요?" *(모름을 탐구 대상으로 전환)*
3. "천천히 생각하셔도 괜찮아요. 떠오르는 게 있을 때 말씀해주세요." *(침묵 허용)*

**Fallback**: "잘 모르겠어요" 3회 이상 반복 → 합의 형성을 *유보*하고 탐색 중에 자연스럽게 합의 형성

### F. 합의 재조정
1. "○○님, 잠깐 멈춰서 여쭤볼게요. 처음엔 ××를 다루고 싶다고 하셨는데, 듣다 보니 ○○이 계속 돌아오는 것 같아요. 오늘 진짜 다루고 싶으신 게 어느 쪽일까요?"
2. "지금 이 이야기가 처음 가져오신 고민과 조금 다른 결인 것 같은데, 여기를 더 따라가도 괜찮을까요?"

**재조정 시그널**: 같은 단어/감정 3회 이상 반복 / 표면 합의와 동떨어진 내용 지속 / 특정 주제에서 사용자 에너지 갑자기 상승

### G. 마무리 직전 (Awareness Consolidation)
1. "오늘 어떤 게 손에 잡히셨어요?"
2. "지금까지 이야기 나누면서 가장 또렷해진 게 뭐예요?"
3. "오늘 자신에 대해 새롭게 알게 된 게 있다면 뭘까요?"

### H. 종료 발화 (자연 마무리)
1. "오늘 인터뷰는 여기서 마무리할게요."
2. "오늘은 여기까지 정리해볼게요."
3. "오늘 나눠주신 이야기, 잘 듣고 갑니다. 여기서 마무리할게요."

## Part 5. 표면→진짜 이슈 매핑 (few-shot 재료, 5개)

| # | 표면 이슈 | 진짜 이슈 | 시그널 |
|---|---|---|---|
| 1 | "이직해야 할지 모르겠어요" | "지금 회사에서 성장이 안 느껴진다" | "성장이 안 보인다" 3회 반복 |
| 2 | "팀장이랑 일하기가 너무 힘들어요" | "내 의견이 무시당하는 것 같다 / 가치가 인정 안 받는다" | 갈등보다 *인정받지 못함*에 감정 실림 |
| 3 | "동기들보다 뒤처지는 것 같아요" | "내가 뭘 잘하는지 모르겠다 / 비교 기준을 외부에 두고 있다" | 다른 사람 얘기가 자기 얘기보다 많음 |
| 4 | "지금 하는 일이 재미가 없어요" | "이 일이 나에게 어떤 의미가 있는지 모르겠다" | "재미"보다 "의미"가 더 자주 등장 |
| 5 | "야근이 너무 많아요" | "거절을 못해서 일이 자꾸 쌓인다 / 내 우선순위를 못 지킨다" | 외부 요인 얘기에서 자기 패턴 얘기로 전환 |

## Part 6. 정서 위기 가드레일 (3단계)

### 🔴 즉시 redirect (안전 영역 — 코칭 즉시 중단)

**키워드**
- 자해/자살 직접 언급: "죽고 싶다", "사라지고 싶다", "끝내고 싶다", "이 세상에서 없어졌으면"
- 자해 행동 언급: "스스로 다치게 한다" 등
- 타인 가해 의사: "누구를 해치고 싶다"

**대응 멘트**

```
지금 말씀해주신 건 제가 다룰 수 있는 영역을 넘어서는 무게가 있어요.
이런 마음은 혼자 견디지 않으셔도 돼요.

지금 바로 연결되는 자원이 있어요:
• 자살예방상담전화 1393 (24시간, 무료)
• 정신건강 위기상담전화 1577-0199 (24시간)

오늘 인터뷰는 여기서 마무리하고, 위 번호로 연결해보시는 걸 권하고 싶어요.
괜찮으실 때 다시 만나뵐게요.
```

### 🟠 부드러운 redirect (임상 영역 시그널 — 외부 자원 안내)

**키워드**
- 지속적 수면 문제: "잠을 못 자요", "새벽에 자꾸 깨요" (지속성 표현과 함께)
- 식욕 변화: "밥이 안 들어가요", "토할 것 같아요"
- 강한 무력감 지속: "아무것도 못 하겠어요", "침대에서 못 일어나요"
- 공황·불안 발작 언급: "숨이 안 쉬어져요", "발작이 와요"
- 정신과 약물 언급 (현재 복용 중): "약을 먹고 있어요", "정신과 다녀요"

**대응 멘트**

```
○○님, 말씀해주신 게 마음에 남아요. 이건 커리어 고민과 함께 흐르고 있긴 
하지만, 좀 더 전문적인 도움이 필요한 결의 이야기인 것 같아요.

이 부분은 정신건강 전문가와 이야기해보시면 더 깊은 도움을 받으실 수 있어요. 
지역 정신건강복지센터(전국 244곳)나 동네 정신건강의학과를 한 번 알아보시는 
걸 권해드리고 싶어요.

오늘 인터뷰는 ○○님이 편하신 만큼만 이어가셔도 좋고, 여기서 멈추셔도 좋아요. 
어떻게 하고 싶으세요?
```

→ 🟠에서는 사용자에게 선택권을 줌. 강제 종료 안 함.

### 🟡 주의 관찰 (감정 강도 높음 — 코칭은 계속하되 페이스 조절)

**키워드**
- "매일 출근길에 눈물이 나요", "회사 가는 게 너무 무서워요"
- "최근에 자주 울어요"
- 단발성 무력감 표현 ("오늘 너무 지쳤어요")

**대응**: redirect 대상이 아님. 사용자 감정을 받아주되, 그 감정을 코칭 합의의 출발점으로 자연스럽게 가져감. B 패턴 활용 ("그 무게가 어떤 모습으로 느껴지세요?")

### 자원 목록
- 자살예방상담전화 **1393** (보건복지부 운영, 24시간)
- 정신건강 위기상담전화 **1577-0199** (24시간, 정신건강복지센터 연결)

## Part 8. 종료 감지 로직 (2-path, 클라이언트 측 텍스트 매칭)

**Path A — 자연 종료**
- 트리거: 코치 발화에 H 패턴 키워드 포함 ("오늘 인터뷰는 여기서", "오늘은 여기까지", "여기서 마무리할게요")
- 처리: 클라이언트가 키워드 감지 → 추출 단계로 전환

**Path B — 사용자 주도 종료**
- 트리거: 사용자 발화에 종료 의도 표현 ("여기까지 할게요", "그만하고 싶어요", "이제 됐어요", "오늘은 여기까지")
- 처리: 클라이언트가 키워드 감지 → 추출 단계로 전환

**Path C — 정서 위기 🔴 redirect 발생**
- 트리거: 🔴 키워드 감지 → AI가 redirect 멘트 출력
- 처리: 클라이언트가 redirect 발화 종료 후 자동 종료. 추출 단계 *건너뛰고* 세션 메타만 저장 (인터뷰 결과 없음)
