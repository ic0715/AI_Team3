## 미검증 가설 (추가 인터뷰 필요)

1차 인터뷰에서 도출된 가설로, 아직 검증되지 않음.

- 사회 초년생(1~3년차)은 시니어와 달리 AI 인터뷰를 더 긍정적으로 받아들일 수 있다 → 인터뷰 없음
- 강점 진단 없이 바로 커리어 인터뷰로 진입하는 플로우가 더 자연스러울 수 있다 → 검증 필요
- AI 인터뷰 턴 수를 5~7개로 제한하면 완주율이 올라갈 수 있다 → 검증 필요
