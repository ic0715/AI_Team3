# 07. 커리어 인터뷰 인트로

> 강점 결과를 확인한 유저가 커리어 방향 탐색으로 자연스럽게 전환하도록 동기를 부여하는 안내 화면.

## 1. 화면 개요

| 항목 | 내용 |
| --- | --- |
| 화면 ID | 07_career_intro |
| 페이즈 | DIRECTION |
| 역할 | 커리어 인터뷰 사전 안내, 강점 → 커리어 전환 동기 부여 |
| 이전 화면 | 04 강점 선택 (직접 선택 경로) 또는 06 강점 결과 (AI 인터뷰 경로) 또는 15에서 재진입 |
| 다음 화면 | 08 커리어 인터뷰 |

## 2. 진입 조건

- 04에서 5개 강점 직접 선택 후 "다음으로" 클릭 (직접 선택 경로) 또는 06에서 "커리어 방향 찾기로 →" 클릭 (AI 인터뷰 경로)
- 또는 15에서 "커리어 방향 재설정" 요청 시 (이때 안내 문구 일부 변경)

## 3. UI 구성 `v1.5 — 상단 고정 + swipe deck + gating 구조로 재구성`

상단 고정(STEP 2 + 강점 Top 5) + **가로 swipe deck 4장**(코칭 교육 3장 + 준비 완료 1장) + 하단 네비게이션. 마지막 카드의 시작 버튼은 **앞 3장을 모두 "이해했어요" 확인해야 활성화**되는 gating 구조. 컨테이너 가로 폭은 기존 그대로 (`w-[390px]`).

### 3.1 상단 바 (고정)

- 뒤로가기 → 06 또는 15
- 페이지 타이틀: "커리어 인터뷰"

### 3.2 상단 고정 영역 (FIXED top)

deck 위에 항상 보이는 영역. 사용자가 어느 카드에 있든 *지금 무엇을 배우는 중인지* + *내 강점은 무엇인지* 컨텍스트가 유지됨.

| 요소 | 내용 |
| --- | --- |
| Step 라벨 | **"STEP 2"** (accent 색, 굵게) |
| 메인 타이틀 | "이제 커리어 방향을 찾아볼 차례예요" |
| 서브 | "강점을 어디에 어떻게 쓸지 함께 정리해요." |
| 강점 카드 | 헤더 "내 강점 Top 5" + chip 5개 (갤럽 34 테마명 그대로, 04 또는 06에서 도출) |

### 3.3 Swipe Deck (4장)

`scroll-snap-type: x mandatory` 가로 스크롤. 카드 1~3은 코칭 교육(각 "이해했어요" 확인 버튼), 카드 4는 최종 준비 화면.

#### 카드 1 — 잠깐, 이건 **코칭**이에요

| 요소 | 내용 |
| --- | --- |
| h2 | "잠깐, 이건 **코칭**이에요" |
| 본문 | "코치는 정답 대신 질문을 던져요. **답은 이미 당신 안에** 있어요." |
| 비교 표 | 컨설팅 ✕ "이렇게 하세요" / 멘토링 ✕ "제 경험으로는…" / **코칭 ✓ "어떻게 생각하세요?"** (강조 행 — accent 보더) |
| 확인 버튼 | "이해했어요" → 클릭 시 "✓ 확인했어요" (accent fill)로 토글, gating 카운트 +1 |

#### 카드 2 — 역량은 스킬, **그 이상**이에요

| 요소 | 내용 |
| --- | --- |
| h2 | "역량은 스킬, **그 이상**이에요" |
| 정의 박스 | **역량 = 지식 + 스킬 + 태도** (3개 term 카드 + `+` 연산자) |
| 본문 | "자격증이나 기술 하나를 알려드리는 게 아니에요. 지식·스킬·태도를 아우르는 **역량 전체**를 함께 봐요." |
| 확인 버튼 | "이해했어요" (gating 카운트 +1) |

#### 카드 3 — 이렇게 진행돼요

| 요소 | 내용 |
| --- | --- |
| h2 | "이렇게 진행돼요" |
| 진행 카드 1 | **주제 합의** — "오늘 다룰 주제를 함께 정해요" |
| 진행 카드 2 | **자유로운 대화** — "정해진 질문지 없이, 큰 고민부터" |
| 진행 카드 3 | **원하는 시간으로** — "보통 30~45분 · 길게 50분+" / **⚠️ 단기간에 풀리지 않아요. 충분히 들여다볼 수 있게 30분 이상을 권장해요.** (경고 색 노란 박스 또는 빨간 텍스트) |
| 확인 버튼 | "이해했어요" (gating 카운트 +1) |

> v1.5 변경: v1.4의 4-card 시각적 안내(⏱/🗣️/🎯/💡) → 코칭 vs 컨설팅·멘토링 비교 + 역량 정의 + 진행 방식 3장 교육형으로 재구성. 사용자가 "코칭이 뭔지" 명시적으로 이해하고 시작하도록.

#### 카드 4 — 준비됐어요! (FINAL)

| 요소 | 내용 |
| --- | --- |
| h2 | "준비됐어요!" |
| 본문 (가운데 정렬) | "솔직하게 답할수록 더 깊은 답이 나와요.<br>이제 코치와 시작해볼까요?" |
| 진행 카운터 | **"N / 3 확인"** (앞 3장 확인 진행률, 회색) |
| Primary CTA | "인터뷰 시작하기 →" — 카운트 < 3이면 회색 disabled, 카운트 = 3이면 accent fill 활성화 |
| 힌트 (조건부) | 카운트 < 3 상태에서 CTA 클릭 시: "← 아직 확인하지 않은 카드가 있어요" (빨간 글씨, 페이드인) |

### 3.4 Bottom 네비게이션

- 좌: prev 화살표 — 첫 카드에서 disabled
- 중앙: dot indicator 4개 — 현재 카드는 길쭉한 pill (accent)
- 우: next 화살표 — 마지막 카드에서 disabled
- 키보드 ← → 키 지원

### 3.5 Gating 메커니즘 `v1.5 신규`

| 동작 | 결과 |
| --- | --- |
| 카드 1·2·3의 "이해했어요" 클릭 | 버튼 토글 (→ "✓ 확인했어요") + confirmedCount 갱신 |
| confirmedCount = 3 도달 | 카드 4의 시작 버튼 disabled 해제 + accent 색 활성화 |
| 시작 버튼 클릭 (활성화 상태) | 08 진입 (sessionStorage 이어하기 다이얼로그 정책 §4 참조) |
| 시작 버튼 클릭 (disabled 상태) | "아직 확인하지 않은 카드가 있어요" 힌트 표시 |

> v1.5 결정 배경: 기존 4-card 안내 카드는 *스크롤하면 다 봤다고 가정*했으나, 사용자가 카드를 실제로 읽고 이해했는지 검증할 수단 없음. gating으로 명시적 확인 강제 → 코칭이 무엇인지·왜 30분 이상 필요한지 사용자가 인지한 상태에서 인터뷰 진입.

## 4. 기능 `v1.4 수정 — v0.9 세션 시간 정책 반영`

- 시작 클릭 → 08 진입 (별도 세션 생성 없음 — 대화는 브라우저 메모리에서만 진행)
- sessionStorage에 진행 중인 대화가 있으면 이어하기 다이얼로그 (브라우저 내에서만 가능)
- `strength_analyses` (is_latest=true) 읽어서 인터뷰 prompt에 자동 포함
- **세션 시간 선택은 본 화면이 아닌 08 진입 직후 첫 단계(Phase 1 Opening)에서 코치의 자연어 질문으로 수집**됨. 본 화면은 시간 범위(15~50분)만 사전 안내. 추출된 값은 `career_interview_results.session_duration_choice` (`short`/`medium`/`long`)로 저장됨 (schema v0.9).
