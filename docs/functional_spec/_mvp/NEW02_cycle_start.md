## 3. UI 구성 `v1.5 수정 — Hero 분리·요약 카드 4행·권유 메시지 박스 신규`

### 3.1 상단 바

- 좌측: spacer (뒤로가기 없음 — 1회성 안내 화면)
- 페이지 타이틀: "커리어 방향 설정 완료"
- 우측: spacer

### 3.2 Hero 영역

- 일러스트: **🚀** (56px, 중앙 정렬)
- 메인 타이틀: **"준비 완료!\n실행을 시작해요"** (🎉 이모지 제거 — 🚀 일러스트로 분리)
- 서브 카피: **"지금까지 선택한 내용을 정리했어요."**

### 3.3 요약 카드 (4행)

요약 카드는 좌측 라벨 + 우측 값 형태의 4개 행으로 구성. 행 구분선(border-bottom)으로 구분.

| 라벨 | 값 | 데이터 소스 |
| --- | --- | --- |
| 🎯 강점 | Top 5 chip (갤럽 34 테마명) — accent-light 배경 chip, 단순 번호 표기, 순위 강조 없음 | `strength_analyses.strengths` (is_latest=true) |
| 🗺 방향 | goal_title (예: "비판적 사고 기르기") | `goals.goal_title` |
| ✅ 액션 | 선택한 단일 액션 title | `action_items` (week_number=1, 첫 항목) |
| 📅 일정 | "YYYY.MM.DD → YYYY.MM.DD" (시작일 → 종료일, 단일 행에 화살표로 연결) | `goals.started_at` ~ `started_at + 83일` |

> v1.5: 일정 표시 형식이 v1.4의 "시작일: X / 종료일: Y" 2줄 → **"X → Y" 단일 행 화살표 표시**로 변경됨.

### 3.4 권유 메시지 박스 `v1.5 신규`

- 텍스트: **"💡 매일 작은 실행과 회고를 반복하며 커리어를 바꿔가요."**
- 배경: accent-light (연한 파랑)
- 글자 색: accent (진한 파랑)
- 카드 하단에 위치, CTA 위

### 3.5 CTA

- Primary: **"홈으로 가기 →"** — Filled accent 버튼, 전체 너비
- 동작: 클릭 시 11 홈으로 이동

## 4. 기능

- CTA 클릭 시 11 홈 이동 (NEW04 경유 없음 — 00_flow.md v1.7 결정사항: NEW04는 NEW02 직후 자동 노출 폐지, 15 프로필 [알림 설정] 진입으로 변경됨)
- 첫 주 `action_items` (week_number=1)는 10 완료 시 이미 생성되어 있음
- `goals.started_at` 기준 종료일 계산 (started_at + 83일 = 12주 후)

> v1.5 변경: v1.4에 명시되었던 "NEW 프로토타입 v1에서는 본 화면이 임시 종착점" 주석 해제. **프로토타입 v4에서 11 홈이 MVP 종착점 화면으로 신규 구현**되며, NEW02 CTA "홈으로 가기 →" → 11 홈 진입이 MVP에서도 정상 동작.
